会话管理

管理所有用户会话，支持搜索、筛选和分页展示。

核心功能

  • 会话列表展示（分页）
  • 按会话名称搜索
  • 按类型筛选（单聊/群聊）
  • 会话信息卡片式展示
  • 查看消息和删除会话
  • 响应式表格设计

技术栈

Vue 3 TypeScript Element Plus Composition API
访问会话管理
✅ 已完成

消息管理

查看和管理指定会话的所有消息，支持实时交互。

核心功能

  • 消息列表展示（分页/滚动加载）
  • 消息气泡样式（区分发送/接收）
  • 多种消息类型支持
  • 发送、删除、复制、回复消息
  • 标记所有消息已读
  • 导出消息数据

技术栈

Vue 3 TypeScript Element Plus WebSocket

🚀 快速开始

安装依赖

$ cd /www/wwwroot/gameos/admin
$ npm install

启动开发服务器

$ npm run dev
> 访问: http://localhost:8080

访问消息管理模块

1. 登录管理后台
2. 访问: http://localhost:8080/#/message/session
3. 点击"查看消息"进入消息管理页面
